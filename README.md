# התחש · The Labyrinth

משחק פאזל מבוכים לנייד: מחליקים את האצבע, החיה רצה עד שהיא נתקעת, והגוף שלה מתארך מאחוריה. המטרה היא למלא את כל המבוך.

- 60 שלבים ב-6 עולמות של 10 שלבים: החצר, הגינה, הפארק, היער, ההרים, המדבר. המבוכים גדלים ויש בהם יותר מחסומים מעולם לעולם
- אתגר יומי ואתגר שבועי (אותו מבוך לכל השחקנים) עם טבלת מובילים לפי זמן
- דו-קרב אונליין: חדר עם קוד, אותו מבוך לשני השחקנים, מי שממלא ראשון מנצח
- נקודות, בונוס יומי, הזמנת חברים, וחנות עם 8 חיות לקנייה
- גרפיקה בתלת-ממד (three.js), רמזים, ביטול מהלך, צלילים ושמירת התקדמות
- השרת: פונקציות במסד הנתונים של Supabase (טבלאות maze_*)

**לשחק:** https://sasy1301-code.github.io/The-Labyrinth/
